# Changelog

## 1.0.0

- First public release of the standalone CLI and Python package.
- Support L-a DUT readback, L-b schematic/config, L-c oscillator tests, and L-d ISF tests.
- Document user-provided PDK bindings and ship a fictional binding and offline request.
- Configure native executables, environment setup and command wrapping at the site.
- Add bilingual quick starts, offline tests and package checks on Python 3.11 through 3.13.
